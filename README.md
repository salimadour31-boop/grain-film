# grain-film

**FR** — Générateur libre de **grain film procédural** dans le navigateur, idéal pour créer des overlays cinématiques (bruit, grain argentique) à superposer sur vos images ou vidéos. Tout se fait localement : aucune installation, aucune image envoyée, aucune clé API.

👉 **Démo : https://salimadour31-boop.github.io/grain-film/**

## Fonctionnalités

- Grain procédural monochrome ou teinté, intensité et taille réglables.
- Aperçu en temps réel sur fond uni ou image uploadée (reste dans le navigateur).
- Animation optionnelle du grain (vitesse réglable).
- Export PNG de l'overlay transparent ou composite.
- Interface multilingue : français, anglais, taqbaylit.
- Responsive, thème sombre, 100 % client-side.

## Utilisation

1. Ouvrez la démo ou `index.html`.
2. Réglez intensité, taille, teinte et vitesse.
3. Uploadez une image de fond optionnelle.
4. Exportez le PNG de l'overlay ou du résultat.
